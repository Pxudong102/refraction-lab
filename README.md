# 光的折射：云端采集 × 数据分析耦合更新包

## 需要上传到 GitHub 仓库根目录的文件

1. `analysis.html`：新增文件，真实实验数据分析平台（云端班级数据版）。
2. `teacher.html`：替换原文件，顶部新增“数据分析平台”入口。

**不要替换现有 `config.js`。** `analysis.html` 会直接复用你已经配置好的 `config.js` 和 Supabase 教师登录会话。

## 使用流程

1. 学生在 `index.html` 提交实验数据。
2. 教师在 `teacher.html` 登录。
3. 点击顶部“数据分析平台”。
4. `analysis.html` 第一模块自动读取 Supabase 中教师有权查看的数据。
5. 选择班级；默认“同组只保留最新一次提交”。
6. 勾选需要分析的实验组，点击“导入所选实验组”。
7. 进入第二模块做单组寻律，第三模块做双组比较。

## 第一模块新增功能

- 自动识别云端所有班级。
- 显示当前班级提交数、实验组数、有效数据点数。
- 默认同组只使用最新一次提交，避免学生修正后出现重复组。
- 可全选 / 取消全选实验组。
- 点击实验组可预览原始 i、r 数据。
- 一键导入后，内部数据组名称只使用组别名称。
- 保留“手动 / CSV 备用”入口，不依赖网络时仍可继续使用。

## 权限说明

不需要新增数据库表或 SQL 权限。现有 Supabase RLS 已允许 teacher_allowlist 中的教师账号读取 `submissions`，学生/匿名用户仍只能提交、不能读取全班数据。
